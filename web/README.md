# 諮商理論小考

網站網址：[GitHub Pages](https://ayakashen.github.io/counseling-theory-quiz/web/)

20題單選題，輸入考生代號後送出；伺服器將作答存入Google試算表，成功後回傳總分與逐題結果。

Google Apps Script 部署位址由 config.js 設定。空白時網站會提示尚未完成連線，不會顯示儲存成功。

正確答案及評分邏輯僅保存在 Google Apps Script，網站原始碼不包含答案表。

## 作答紀錄格式

工作表「作答紀錄（每人一列）」：A1 為考生代號，B1 到 U1 依序為第 1 到 20 題的題號與完整題目。第二列起每次送出占一列，A 欄為代號，B 到 U 欄為各題選答。原「作答紀錄」工作表保留供查核；完整舊紀錄會轉換到新工作表，重跑轉換與重試送出不會重複新增紀錄。
